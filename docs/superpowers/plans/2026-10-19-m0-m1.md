# M0 + M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Validated parameter JSON → one-storey flat-roof house in headless Blender → 10 sequential renders → `model.blend`, `model.glb`, contact sheet and checksummed `delivery.json` in a fresh revision directory, plus the M0 repo/CI foundation.

**Architecture:** Host Python validates and normalizes `project.json` (Pydantic), computes all geometry and camera poses as a pure-Python `scene_plan.json`, then a runner invokes fixed Blender scripts (build → render) as one sequential subprocess at a time, tracking `job.json` and packaging the delivery. Blender scripts use only stdlib + `bpy`/`mathutils`.

**Tech Stack:** Python 3.13, Pydantic 2, Pillow, argparse, pytest, ruff, pip-audit; Blender 5.2.2 LTS (embedded Python 3.13.13); GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-19-m0-m1-design.md` (approved 2026-10-19). Read it before any task.

## Review Focus

1. Paths containing spaces (project file, output dir) → build works. Test: `test_build_with_spaces_in_paths` (Task 8).
2. Malformed `project.json` (bad JSON syntax, UTF-8 BOM, top-level list) → one clear error, exit 2, no traceback. Test: `test_validate_malformed_json_exit_2` (Task 9).
3. Blender missing or wrong path → exit 3 with message naming `EXTERIOR_AGENT_BLENDER`; `doctor` reports `blender.found = false` instead of crashing. Tests: `test_build_without_blender_exit_3`, `test_doctor_without_blender` (Task 9).

5. Opening exactly on a limit (`offset == t`, `sill + height == wall_height − 0.10`, pier gap exactly `0.10`) → accepted; 2 mm beyond → rejected. Whole project in `mm` → same normalized values as `m`. Tests: `test_opening_on_limits_accepted`, `test_opening_beyond_limits_rejected`, `test_mm_project_equals_m_project` (Task 2).
